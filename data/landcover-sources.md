# 실제 토지피복 관측 연결

`landcover-data.mjs`는 [NASA ORNL DAAC TESViS 공개 API](https://modis.ornl.gov/data/modis_webservice.html)를 통해 지정 좌표의 MCD12Q1 연도별 관측을 요청합니다. 확인일은 2026-09-15입니다. 제공 연도를 먼저 조회하며, 현재 시점의 지표를 실시간 촬영한 것처럼 표시하지 않습니다.

- 지점 하나의 실제 MODIS 픽셀을 요청합니다. 명목 해상도는 500 m이고 API의 실제 격자 크기는 약 463.313 m입니다. 한 지점의 결과를 화면 전체의 검증 결과로 확대하지 않습니다.
- LC_Type1, QC, LW를 같은 요청에서 받고 날짜·타일·처리 시각을 맞춥니다. API는 한 번에 최대 10개 관측일만 허용하므로 연도 목록 1회와 최대 3개의 묶음 요청을 사용합니다. 30개를 넘는 오래된 연도는 `period.omittedOlderYears`에 표시합니다.
- QC는 비트마스크나 정확도 백분율이 아닌 범주 코드입니다. QC=0·LW=2인 분류된 육지와 QC=2·LW=1인 분류된 수역만 채택합니다. 보충·재분류·미분류 값은 제외하며 원값과 이유를 보존합니다. 특히 QC=1의 나지는 결측으로 인한 대체값일 수 있으므로 사실 관측으로 쓰지 않습니다.
- 결측을 0으로 채우거나 과거의 마지막 정상값을 최신 관측처럼 대체하지 않습니다. 요청 URL, 조회 시각, 관측 연도, 처리 시각, 실제 픽셀 위치를 결과에 담습니다.
- 현재 ORNL 응답은 collection 식별자를 반환하지 않습니다. 앱은 이를 `null`로 명시하고 [C6/C6.1 공통 제품 범례](https://lpdaac.usgs.gov/documents/1409/MCD12_User_Guide_V61.pdf)를 사용합니다.

**이 자료만으로 실제 토지피복 변화나 사막화를 판정하지 않습니다.** 제품 안내서는 연도별 분류명의 불확실성 때문에 연간 분류를 직접 비교해 실제 변화를 검출하지 않도록 안내합니다. `labelDifference`는 두 해의 분류명이 같은지만 설명하며 `verifiedLandCoverChange`와 `desertificationVerdict`는 항상 `null`입니다. 나지라는 분류도 사막화 진행의 증거가 아닙니다.

단위 검사는 품질 상태, 결측·잘못된 배열, 날짜와 처리 시각 불일치, 수역 교차 확인, 요청 묶음, 중단·통신 오류를 확인합니다. 정확도를 입증하는 현장 검증을 수행한 것은 아닙니다.
