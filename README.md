# LAND:15

UN SDG 15.3의 사막화 방지 목표를 주제로 만든 교육용 의사결정 웹 프로토타입입니다.

## 핵심 흐름

- Esri World Imagery 실제 위성영상 베이스맵 표시
- 지도에서 두 모서리를 클릭해 원하는 분석 구역 지정
- 선택 영역을 48 × 32, 총 1,536개 미세 격자로 분석
- Sentinel-2 형식의 환경지표 모의 데이터 생성
- Gaussian Naive Bayes를 이용한 사막화 위험등급 분류
- Voronoi 방식의 최근접 관리구역 배정
- Greedy 방식의 예산 내 복원 우선지역 선정
- Prim 최소 신장 트리를 이용한 복원 거점 연결
- A*를 이용한 현장 접근경로 예시

## 실행

별도 빌드 과정이 없는 정적 웹앱입니다. `index.html`을 브라우저에서 열거나 로컬 정적 서버로 실행할 수 있습니다.

```bash
python -m http.server 8000
```

## 분석 구역 선택

1. 대상 지역에서 고비·사헬·아랄해 중 하나를 선택합니다.
2. 더 좁은 구역을 보려면 `지도에서 분석 구역 지정`을 누릅니다.
3. 위성지도에서 분석할 사각형의 첫 번째 모서리와 반대편 모서리를 차례로 클릭합니다.
4. 선택한 위·경도 범위에 맞춰 격자, 위험도, 추정 면적과 복원 우선순위가 다시 계산됩니다.

## 데이터 주의사항

배경 지도는 실제 위성영상이지만 촬영 시점과 해상도는 지역마다 다르며 실시간 영상은 아닙니다. 위험도·NDVI·강수량 등 분석 수치는 인터랙션과 알고리즘 흐름을 시연하기 위한 합성 데이터입니다. 실제 분석으로 확장하려면 Google Earth Engine 또는 Copernicus Data Space에서 Sentinel-2 L2A 영상을 가져와 구름 제거, 월별 합성, 학습자료 구축과 현장 검증을 추가해야 합니다.
