# LAND:15 — 실제 관측 3D 아틀라스

[배포 사이트](https://leejuhan-1214.github.io/ToGangDDaKK/) · [교육용 시뮬레이션](https://leejuhan-1214.github.io/ToGangDDaKK/simulation.html)

실제 표고와 위성영상 위에서 공개 황폐화 격자, NASA 생산성 시계열, 토지피복 및 UN 국가 보고 통계를 대조하는 웹앱입니다. 기본 화면의 분류·수치는 제공기관의 자료를 읽으며, 결측이나 연결 실패를 임의 위험점수로 대체하지 않습니다. 자료의 관측 연도·해상도·품질과 서로 다른 결과를 함께 보여줍니다.

**지도를 움직이면 자료를 다시 조회하지만, 위성이 지금 촬영하는 실시간 사막화 진단은 아닙니다.** 공개 전 지구 산정 자료, 국가 보고, 현장 검증을 구분합니다. 사막화의 확정이나 미래 위험 확률은 제공하지 않습니다.

## 실행·검사·빌드

Node.js 22 이상을 권장합니다. 지도 렌더러·GeoTIFF 판독기·글꼴이 포함되어 있어 별도 패키지 설치 없이 실행할 수 있습니다.

```sh
node server.mjs
```

[로컬 미리보기](http://127.0.0.1:4173/)에서 실행합니다. 위성영상, 표고, NASA 조회 및 황폐화 COG에는 인터넷 연결이 필요합니다.

```sh
node --check live-app.mjs
node --check degradation-data.mjs
node --check observation-data.mjs
node --check landcover-data.mjs
node --check unccd-reference.mjs
node --test
node build.mjs
```

자동 검사는 코드·격자·단위·품질 조건, 좌표 변환, 결측 처리, 요청 취소, 부분 다운로드 제한 등을 검사합니다. 시뮬레이션의 기존 수치·수역 회귀 검사도 포함합니다. 테스트 통과가 위성 자료의 현장 정확도 검증을 뜻하지는 않습니다.

2026-09-15 전체 자동 검사 146개를 통과했습니다. 실제 API 연결과 네 가지 화면 크기의 브라우저 점검은 [검증 기록](VALIDATION.md)에 정리했습니다. 지도 탭의 **지구 전체**로 지구본을 보고, 확대하면 실제 DEM 지형을 탐색할 수 있습니다.

`main`에 게시한 변경은 GitHub Actions에서 검사한 뒤 `dist/`의 정적 파일로 GitHub Pages에 배포합니다. API 비밀키나 별도의 분석 서버를 요구하지 않습니다.

## 기본 화면에서 할 수 있는 일

- **3D 지도:** 실제 표고 1배, 지역별 정밀 DEM 자동 선택, 위성·항공 영상과 경사 기반 음영을 표시합니다. 최대 22단계 확대와 카메라 기울기 조절을 지원합니다.
- **화질·실사:** 존재하는 고해상도 영상을 우선 사용하고 원본 해상도를 넘으면 보간임을 표시합니다. 선명도 보정 켜기/끄기와 선택 좌표의 Google Earth·주변 Street View 연결을 제공합니다. 새 관측 정보를 복원하는 기능은 아닙니다.
- **화면의 황폐화 개요:** 이동을 멈추면 공개 COG에서 필요한 부분을 읽어 해당 범위의 2023 상태를 표시합니다. 축소 지도는 대표 분류이며 면적 통계가 아닙니다.
- **지점 조회:** 지도에서 누르거나 좌표를 입력해 원본 해상도의 황폐화 분류와 하위 지표를 확인합니다. 자동 조회를 켜면 이동 후 화면 중심을 조회합니다.
- **방법 간 대조:** Trends.Earth와 JRC 생산성 방법으로 만든 결과를 비교하고 일치·불일치·자료 부족을 구분합니다.
- **위성 생산성:** NASA의 공개 연간 순일차생산량(NPP)을 품질 검사한 뒤 시계열과 탐색적 추세를 보여줍니다. 강수와 토지피복은 별도의 맥락 자료입니다.
- **국가 보고 맥락:** 선택 위치의 UN SDG 15.3.1 국가 비율을 보고 연도·자료 성격과 함께 표시합니다. 국가 비율을 지점 확률로 변환하지 않습니다.
- **근거 확인·저장:** 출처, 품질, 관측 기간, 원본 픽셀, 불일치 및 실패한 요청을 확인하고 조회 결과를 JSON으로 저장합니다.
- **연도 비교:** 별도 화면에서 2001·2010·2020·2025년 8월 NASA 식생지도와 고비·사헬·아랄 대표점의 NDVI·강수를 비교합니다. 기본 3D 지도와 별도의 과거 자료 보기입니다.

### 실제 높이와 음영

Mapterhorn의 Terrarium 타일을 `R×256 + G + B/256 − 32768` m로 해독합니다. 위성영상의 색이나 밝기를 높이로 바꾸거나 임의의 굴곡을 추가하지 않습니다. Copernicus GLO-30을 전 지구 기본으로 사용하며 지역에 따라 공개 측량 자료가 결합됩니다. 앱은 공통 범위를 위해 DEM 최대 줌을 12로 제한하므로 이후 확대가 새로운 표고 정밀도를 만들지는 않습니다.

음영은 같은 표고의 경사·방향에서 계산한 약한 다방향 조명입니다. 촬영 당시 태양이나 지형이 드리우는 실제 그림자의 복원이 아닙니다. 표고의 원자료 시기·수평/수직 오차·보간과 수목·건물의 영향이 남습니다. 평탄한 곳은 실제로 평탄하게 표시합니다. Google Earth의 사진측량 건물 메시나 일본 PLATEAU·스위스 도시 메시를 통합했다고 주장하지 않습니다. [표고 출처와 점검 범위](data/terrain-sources.md)

### 황폐화 COG의 14개 밴드

[Trends.Earth SDG Indicator 15.3.1 Datasets v1.2](https://doi.org/10.5281/zenodo.17514520)는 2025-11-03 발행 자료입니다. 실제 TIFF의 좌표계·밴드 수·결측값·격자 위치를 확인한 뒤 읽습니다. 세 자료의 격자는 같지 않으므로 동일 좌표에 해당하는 각 자료의 원본 픽셀을 조회합니다.

| 밴드 | 내용 | 기간·단위 |
| --- | --- | --- |
| 1 / 5 / 10 | SDG 15.3.1 평가기간 분류 | 각각 2000–2015 / 2004–2019 / 2008–2023. −1 황폐화, 0 변화 없음, 1 개선 |
| 2 / 6 / 11 | 토지생산성 변화 | 2001–2015 / 2004–2019 / 2008–2023. 감소·완만한 감소·스트레스·안정·증가 |
| 3 / 7 / 12 | 토지피복 황폐화 분류 | 2000–2015 / 2015–2019 / 2015–2022 또는 2023. −1 / 0 / 1 |
| 4 / 8 / 13 | 토양 유기탄소 변화 | 같은 세 기간. 0–30cm 탄소의 **변화율(%)**, 분류 코드가 아님 |
| 9 / 14 | 기준기간 대비 토지 상태 | 각각 2019 / 2023 상태. 황폐화 지속·최근·기준기간, 안정, 개선 기준기간·최근·지속의 7개 분류 |

12·13번 밴드의 마지막 연도가 **발행 메타데이터에는 2022, 실제 TIFF 설명에는 2023**으로 다릅니다. 이 차이를 출처 문서와 결과 설명에 남기며, 독립적으로 확인한 연도라고 단정하지 않습니다. 모든 밴드의 결측 코드 `−32768`은 유효값으로 해석하지 않습니다.

**평가기간의 변화 없음과 현재 상태의 안정은 다른 결과입니다.** 예를 들어 두 방법의 10번 밴드가 모두 0이어도, 14번 밴드는 한쪽이 ‘기준기간 황폐화’, 다른 쪽이 ‘안정’일 수 있습니다. 변화 분류가 같다는 이유로 상태의 불일치를 숨기지 않습니다. 14번 상태와 10번 평가기간 분류는 각각 비교합니다.

세 제품은 생산성 방법이 다르지만 토지피복·토양 탄소 입력을 공유합니다. 일치는 **방법 선택에 따른 결과의 민감도 확인**이며 독립적인 현장 검증이나 정확도 확률이 아닙니다. 관측 원인·건조지 여부·공간 및 시기 정합성과 현장 대조 없이 사막화를 확정하지 않습니다. [COG 출처·코드·제약](data/degradation-sources.md)

### 화면 범위 읽기와 원본 지점 읽기

TE 원본은 약 7.8GB이지만 브라우저가 전체 파일을 내려받지 않습니다. Google 공개 다운로드 API에서 HTTP 206 바이트 범위를 요청하고, 응답 범위와 크기를 검사합니다. 전체 파일을 반환하는 HTTP 200 응답은 본문을 읽지 않고 거부합니다. 타일·캐시·시간·전송량 한도를 두고 필요 부분만 읽습니다.

지도에는 COG의 MODE 축소 영상을 최근접 방식으로 표본화할 수 있습니다. Mercator 행 좌표를 반영하며 범주 코드 사이를 보간하지 않습니다. 축소 과정에서 소규모 황폐화가 사라질 수 있으므로 개요 셀 개수로 황폐화 면적이나 비율을 계산하지 않습니다. 지점 결과는 축소 영상 대신 원본 픽셀에서 읽습니다. 요청 취소·실패·잘못된 코드·결측은 미판정으로 처리합니다.

### NASA 생산성 품질과 추세

NASA ORNL에서 해당 위치의 제공 날짜와 원자료를 조회합니다. 완료된 연도만 사용하며 조회 시각·관측 연도·임시 저장 사용 여부를 구분합니다. 제품의 물·나지·눈·도시·결측 등 제외 코드를 낮은 생산성이나 높은 위험도로 바꾸지 않습니다. 품질값이 유효한 0–100 범위이고 앱의 기준 50 이하인 관측만 추세에 사용합니다. 원본 값과 제외 이유도 보존합니다.

최소 15개 유효 연도와 요청 기간의 70% 이상 자료가 있을 때 Theil–Sen 기울기와 동률·연속성 보정을 적용한 Mann–Kendall 검정으로 탐색적 경향을 계산합니다. 명목 p값은 시계열 자기상관이나 여러 지점을 반복 검사하는 효과를 보정하지 않았습니다. 이를 인과관계·독립 검증·사막화 확률로 표현하지 않습니다. 자료가 부족하면 추세 판정을 보류합니다.

MCD12Q1은 토지피복·품질·육지/수역 밴드의 날짜·타일·처리 버전과 분류 일관성을 검사합니다. 분류를 보충·재수정한 품질 상태는 제외합니다. POWER 강수는 월평균 일강수량에 월 일수를 곱해 합산하며, 한 달이라도 결측이면 그 연도를 제외합니다.

### UN 국가 통계

`AG_LND_DGRD` 시계열의 보고 연도·단위·자료 성격·보고 기관·각주를 보존합니다. 현재 묶음 자료는 342개 관측, 국가·지역 150개 중 수치가 있는 곳 121개와 별도로 분리한 지역/세계 합계 21개를 포함합니다. 관측 연도는 2015·2019입니다. 한국처럼 유효한 국가 수치가 없는 곳은 ‘자료 없음’으로 표시합니다.

국가 경계는 Natural Earth 1:50,000,000 일반화 자료입니다. 바다에 가장 가까운 국가의 비율을 붙이지 않으며 작은 섬·해안·분쟁 경계는 미확인 또는 불확실할 수 있습니다. 국가 비율은 지도 전체나 특정 픽셀이 황폐화됐을 확률이 아닙니다. [UN 원자료·범위](data/unccd-sources.md)

## 교육용 모형은 별도 화면

`simulation.html`은 기존 과제의 알고리즘과 발표 기능을 보존한 **교육용 합성 시뮬레이션**입니다. 환경지표·NB/CA 위험점수·관리거점·비용·주민 영향·복원 효과는 합성값이며 기본 관측 화면의 검증값으로 사용하지 않습니다.

- NB + CA, Voronoi, Greedy, Prim + A* 단계와 복원 전후 가정을 탐색합니다. NB 모수는 실제 자료로 학습·보정한 예측확률이 아닙니다.
- 원본을 바꾸지 않고 선정 셀 점수를 가정에 따라 낮춥니다. 결과 카드·발표·CSV는 관측된 복원 효과나 정책 근거가 아닙니다.
- 화면을 따라 이동하는 64×48 격자, 육지 클리핑, 위험 요인 민감도 설명, 5단계 발표와 PNG 카드 등 이전 기능은 이 화면에 있습니다.
- Natural Earth 1:10,000,000 land에서 lakes를 뺀 일반화 경계로 수역을 제외합니다. 실제 도로·최신 해안·국경 통제·모든 소하천을 반영한 경로 계획은 아닙니다. [육지 마스크 출처](data/README.md)

연도 비교의 지도는 NASA 월 합성 영상, 대표점 NDVI는 250m 픽셀의 16일 합성입니다. 두 자료의 시간 범위가 같지는 않습니다. 지도 이동으로 고정 참조점 그래프가 바뀌지 않으며, 구름 등 품질 미충족은 결측으로 남습니다. [과거 자료의 품질·재현법](data/history-sources.md)

| `degradation-data.mjs` | COG 원본 지점·축소 지도 부분 읽기, 분류와 방법 비교 |

| `vendor/` | MapLibre, GeoTIFF.js, polygon-clipping, SUIT 및 각 라이선스 |
| `build.mjs`, `server.mjs`, `.github/workflows/pages.yml` | 정적 빌드·미리보기·GitHub Pages 배포 |

국가 통계와 COG 메타데이터는 사이트에 포함된 조회일 기준 스냅샷입니다. 자동으로 최신 보고서를 발견한다고 주장하지 않습니다. 의도적으로 갱신할 때 다음 스크립트를 실행하고 변경된 연도·단위·코드·출처 및 테스트를 검토합니다.

```sh
node scripts/fetch-unccd.mjs
node scripts/fetch-degradation-cogs.mjs
node --test
node build.mjs
```

외부 제공기관 장애나 자료 변경으로 일부 조회가 실패할 수 있습니다. 계정 동기화나 서버 저장은 없으며, 분석 근거 저장은 사용자가 내려받는 JSON 파일입니다.
