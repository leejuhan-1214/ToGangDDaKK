# LAND:15

UN SDG 15.3의 사막화 방지 목표를 주제로 만든 교육용 의사결정 웹 프로토타입입니다.

## 핵심 흐름

- Sentinel-2 형식의 환경지표 모의 데이터 생성
- Gaussian Naive Bayes를 이용한 사막화 위험등급 분류
- Voronoi 방식의 최근접 관리구역 배정
- Greedy 방식의 예산 내 복원 우선지역 선정
- Prim 최소 신장 트리를 이용한 복원 거점 연결
- A*를 이용한 현장 접근경로 예시

## 실행

별도 빌드 과정이 없는 정적 웹앱입니다. `index.html`을 브라우저에서 열거나 로컬 정적 서버로 실행할 수 있습니다.

```bash
python -m http.server 8000
```

## 데이터 주의사항

현재 화면의 수치와 공간 데이터는 인터랙션과 알고리즘 흐름을 시연하기 위한 합성 데이터입니다. 실제 분석으로 확장하려면 Google Earth Engine 또는 Copernicus Data Space에서 Sentinel-2 L2A 영상을 가져와 구름 제거, 월별 합성, 학습자료 구축과 현장 검증을 추가해야 합니다.

## 교과 융합

- 확률과 통계: 베이즈 정리, 조건부확률, 성능지표
- 지구과학: 위성 원격탐사, 기후와 토양
- 세계지리: 건조지역, 인간의 토지 이용
- 정보: 분류·그래프·공간·최적화 알고리즘
